# Mahjong Score Manager

麻雀スコア管理アプリケーション

React + TypeScript + Viteで構築された麻雀のスコア管理システムです。

## 機能

- プレイヤー管理
- ラウンドごとのスコア記録
- 統計とダッシュボード
- イベント管理

## 技術スタック

- React 19
- TypeScript
- Vite
- Tailwind CSS
- Capacitor (モバイルアプリ化)

## セットアップ

```bash
npm install
npm run dev
```

## ビルド

```bash
npm run build
```

## モバイルアプリ

Capacitorを使用してAndroidアプリとしてビルドできます。

```bash
npm run build
npx cap sync
```
